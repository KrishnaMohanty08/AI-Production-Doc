SAFETY BY DESIGN

Automation without the chaos.

Guardrails keep the documentation pipeline controlled, efficient and predictable.

∞

No infinite loops

[skip ci] prevents generated doc commits from retriggering the workflow.

◫

Token aware

Large diffs are truncated to keep requests within safe API limits.

!

Fail fast

HTTP and empty-response guards stop bad generations before they reach your docs.

⌁

Idempotent

The engine commits only when generated documentation actually changes.

◷

Timeout protected

API requests have a 60-second timeout to prevent hanging workflows.

⊘

Ignore what matters

.llmignore keeps lock files, binaries and unwanted paths out of AI processing.

PRIVACY & SYSTEM DATA

Your code stays under control.

AI DevDocs processes the repository information required to generate and maintain project documentation.

⌁

Repository Changes

Git diffs and commit context are processed so the documentation engine can understand what changed in the project.

⊘

Ignored Files

.llmignore keeps excluded files, binaries and unwanted paths out of AI processing.

◇

API Key Protection

API credentials are configured through GitHub Secrets instead of being written directly into the public codebase.
